# Downpour Next v0.1.22

Visual refinement of the existing rain-and-blossom desktop: tapered branches and textured bark, a coordinated navigation header and dark cyan/violet panel, and shared chart frames with restrained accent rules and corner details. Charts keep their measured values, units, tooltips, accessible summaries and severity colors. Decoration adds no polling or animation work; rain and reduced-motion controls remain available.

Includes v0.1.21's local aggregate learning and maximized startup with normal restore/resize/minimize controls.

Devices & Drivers matches Windows Update offers against bounded hardware and compatible identifier sets, with exact-match explanations. Names and ID prefixes no longer imply compatibility. Partial/failed searches and incomplete inventories are visible; driver version/signature changes refresh displayed rows. Installation is clearly labeled as a fresh batch across all offered devices; misleading single-device install buttons are removed. Targeted installation and cancellable WUA searches remain future work.

CIS Copy review report includes local learning from the same completed refresh, including baseline maturity, missing/paused data and explanations. Invalid or mismatched snapshots remain unavailable. Threat assessment no longer increases confidence merely because several potentially overlapping feeds repeat an indicator; exact hashes and observed behavior retain their evidence weight.

Additional source research is recorded in RESEARCH_2026-10-14.md. This release retains 45 feed definitions; no unverified sources or direct Tor crawling were added.

Candidate verification in progress. Publication requires Debug and clean Release checks, native route/window lifecycle checks, verified archive and runtime SBOM. Signing, clean-machine acceptance and full visual/high-DPI accessibility acceptance remain open.
