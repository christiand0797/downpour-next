## In-app operations still to implement

The user requires working operations in Downpour, not links presented as implementation. The audit identified these concrete paths:

1. Protected-log access currently shows a command and opens Computer Management. A typed UAC broker can use [NetLocalGroupAddMembers](https://learn.microsoft.com/en-us/windows/win32/api/lmaccess/nf-lmaccess-netlocalgroupaddmembers) with the authenticated requesting user's SID and the fixed Event Log Readers group, resolving the localized group name from its SID. Record prior membership, avoid arbitrary account/group parameters, and undo only a membership Downpour added using [NetLocalGroupDelMembers](https://learn.microsoft.com/en-us/windows/win32/api/lmaccess/nf-lmaccess-netlocalgroupdelmembers). Test denial, already-member behavior, localization, audit, timeout and sign-out requirements.
2. Devices already installs an explicitly confirmed all-applicable WUA driver batch. A targeted installer needs UpdateID/revision plus fresh hardware applicability revalidation inside the elevated component; it must show partial results and reboot requirements honestly. Read-only search should use [BeginSearch](https://learn.microsoft.com/en-us/windows/win32/api/wuapi/nf-wuapi-iupdatesearcher-beginsearch) and [RequestAbort](https://learn.microsoft.com/en-us/windows/win32/api/wuapi/nf-wuapi-isearchjob-requestabort) with bounded cancellation. No promise of a driver for every device or automatic rollback without a working recovery path.
3. SMB1 client currently opens Optional Features. Native [DismDisableFeature](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/dism/dismdisablefeature-function?view=windows-11) can service a fixed feature through the audited fixer. Capture its prior state, serialize online sessions, expose progress/reboot state, and re-query after cancellation because cancellation can leave an unknown state. Add denial, audit, timeout and rollback tests before enabling.

The existing Windows Update installer also ignores search completion before interpreting the collection. The current milestone corrects that path: an incomplete search must not become an all-clear or a silently installed partial set. This is implemented and tested without running privileged updates on the development PC.

These are single local runs, not whole-service measurements or universal performance guarantees. The two-millisecond memory sampler can miss brief peaks.
